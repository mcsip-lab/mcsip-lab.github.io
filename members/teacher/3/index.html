2026IEEE Transactions on Information Forensics and Security

A Two-Stage Robust Reversible Image Watermarking Scheme Using 2D Lattice QIM With Quantization Strips

Yichao Tang; Zhuangxi Yao; Yingxi Huang; Chuntao Wang; Shijun Xiang

研究概述与图示

该工作研究同时要求水印鲁棒提取与原图无损恢复的图像版权保护问题。方法在两阶段鲁棒可逆水印框架中引入二维格点量化和条带式解码区域，通过量化与解码区域的几何设计扩大稳定译码范围。其目标是在图像发生处理后仍能提取水印，同时控制嵌入失真，并保留无攻击条件下恢复原始图像的能力。

全局-局部统计特征与攻击驱动载体选择的JPEG鲁棒可逆水印

黄颖熙; 王春桃; 汪建才; 汤毅超; 边山

研究概述

该工作面向JPEG图像中的鲁棒可逆水印，在量化DCT域内同时考虑载体稳定性与原图恢复。方法通过多攻击评分和轻量网络选择嵌入载体，并融合均值、中值等全局与局部统计特征进行四频带调制。结合直方图平移保存恢复信息，使水印在图像处理后仍可提取，并支持无攻击条件下的原图精确恢复。

2026IEEE Transactions on Multimedia

A Novel Robust Reversible Watermarking Scheme Using Fractional-Order Polar Complex Exponential Transform

Yichao Tang; Shuai Wang; Ruowei Han; Chuntao Wang

研究概述与图示

针对鲁棒可逆水印难以同时抵抗常规信号处理和几何变换的问题，提出结合分数阶极复指数变换与优化量化索引调制的方法。通过重建误差选择变换参数，并根据攻击模拟中的稳定性选择矩差作为水印载体；嵌入失真与完整性哈希则作为辅助信息可逆嵌入。接收端在无攻击时恢复原图与水印，在受到攻击时提取水印，模拟实验检验了其在相同容量和图像质量条件下的鲁棒性。

2026AAAI

GenPTW: Latent Image Watermarking for Provenance Tracing and Tamper Localization

Zhenliang Gan; Chunya Liu; Yichao Tang; Binghao Wang; Shiwen Cui; Weiqiang Wang; Xinpeng Zhang

研究概述与图示

针对生成图像水印难以同时完成来源追踪和篡改定位、且常受生成模型类型限制的问题，提出潜空间水印框架GenPTW。方法结合与潜语义对齐的交叉注意力融合和提供位置线索的空间融合，再以水印特征和高频特征联合提取来源信息与编辑区域。该框架支持生成中与生成后的嵌入，可用于潜扩散模型和视觉自回归模型；实验评估了视觉质量及多种生成内容编辑下的鲁棒性。

2026IEEE ICASSP

DNLMark: Dual Noise Layer-Based Robust Watermarking Against Image Editing

Yichao Tang; Mingyang Li; Xinting Wu; Sheng Li; Zhenxing Qian; Xinpeng Zhang

研究概述与图示

DNLMark研究图像编辑后水印信息难以稳定恢复的问题。方法在水印网络训练中采用双噪声层，将常规图像失真和模拟的生成式编辑干扰纳入训练流程。研究关注在保留图像视觉质量的条件下，提高水印嵌入与提取面对不同编辑操作时的适应性。

SLMark: Robust Watermarking Against Image Editing via Simulation-Based Noise Layer and Low-Frequency Embedding

Mingyang Li; Yichao Tang; Yuliang Xue; Sheng Li; Zhenxing Qian; Xinpeng Zhang; Ji He; Hongda Li

研究概述与图示

SLMark关注图像经编辑后，嵌入水印随图像内容变化而丢失的问题。方法将基于模拟的噪声层与低频嵌入相结合，在训练中引入编辑干扰，并选择较稳定的频率成分承载水印。研究旨在协调水印的隐蔽性与编辑后的可提取性，为图像内容保护提供鲁棒标识。

A two-stage robust reversible watermarking using polar harmonic transform for high robustness and capacity

Yichao Tang; Kangshun Li; Chuntao Wang; Shan Bian; Qiong Huang

研究概述与图示

针对鲁棒可逆水印在鲁棒性、容量与可恢复性之间的权衡，研究提出基于极谐变换的两阶段方案。首先选取稳定的极谐矩，并通过自适应归一化和优化的失真补偿量化嵌入鲁棒水印，减少需要保存的量化误差信息。随后以可逆嵌入保存恢复所需的辅助信息，使未受攻击的图像能够恢复原始内容。

2024IEEE Transactions on Information Forensics and Security

A Robust Reversible Watermarking Scheme Using Attack-Simulation-Based Adaptive Normalization and Embedding

Yichao Tang; Chuntao Wang; Shijun Xiang; Yiu-Ming Cheung

研究概述与图示

为在版权保护中兼顾鲁棒性和无攻击时的原图恢复，研究利用目标攻击先验设计两阶段鲁棒可逆水印。方法通过大规模攻击模拟评估极谐变换矩的稳定性，据此进行自适应归一化和载体选择，并优化多量化级STDM及嵌入强度；嵌入误差随后以递归编码方式可逆保存。实验在相同不可见性、容量和可逆性条件下，比较了噪声、压缩、滤波及旋转缩放等攻击中的鲁棒性。

2023IEEE Transactions on Circuits and Systems for Video Technology

A Highly Robust Reversible Watermarking Scheme Using Embedding Optimization and Rounded Error Compensation

Yichao Tang; Shuai Wang; Chuntao Wang; Shijun Xiang; Yiu-Ming Cheung

研究概述与图示

该工作提出两阶段鲁棒可逆水印方案，通过优化嵌入和补偿舍入误差改善鲁棒性与容量。第一阶段在选定的伪Zernike矩中嵌入鲁棒水印，使用自适应归一化和优化策略控制失真；第二阶段记录原图与鲁棒水印图之间的误差，实现未受攻击时的无损恢复。论文在常见信号处理、几何变换和压缩感知等攻击下检验水印提取稳定性。
